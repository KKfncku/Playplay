# 卡通风格城市建设模拟游戏设计文档

## 核心概念
- **类型**：轻量级 2.5D 浏览器城市模拟，点选、拖放交互。
- **目标**：平衡经济、环境、社会与治理（ESG）表现，打造可持续城市。
- **循环**：建造/升级 → 产出金币 → 再投资建设 → 解锁高级建筑与城市场景。

## 玩法与系统
- **操作**：
  - 选中建筑卡片拖放至网格地图；支持旋转、移动、拆除（返还部分金币）。
  - 支持多选框移动/拆除，便于整体规划。
- **资源**：金币（自动产出）、人口（解锁需求）、ESG 评分（影响解锁和市民满意度）。
- **建筑类别**：
  - 住宅、商业、产业、公共服务、绿色/可再生、景观与文化。
  - 每类建筑有尺寸、产出、维护、ESG 修正值、升级等级。
- **ESG 指标**：
  - **E**：碳排放、绿化率、能源占比、水资源利用。
  - **S**：就业、教育、医疗、娱乐、住房可负担性。
  - **G**：交通拥堵、治安、基础设施可靠性、预算平衡。
  - 综合评分影响城市等级、随机事件概率与奖励。
- **事件系统**：定期触发“节能周”“产业补贴”“极端天气”等事件，临时调整产出或需求。
- **任务与成就**：新手目标（修建道路、建首个风力发电机）、阶段性目标（达到 ESG B+）、长期成就（零碳工业园）。

## 进程与解锁
- **章节式地图**：
  - 新手草原 → 河畔 → 海湾 → 高原四个场景，地形阻塞与资源限制逐步提升。
- **科技树**：再生能源、公共交通、智慧治理、循环经济等节点，影响建筑解锁与属性。
- **升级路径**：建筑 3–5 级，升级提升效率但增加维护或需求，需要平衡。

## 经济与平衡
- 基础建筑每 10–30 秒产出金币；公共服务消耗金币维护但提升满意度和 ESG。
- 税收与补贴：根据居民与商业数量自动征税，可用治理点数发放补贴平衡指标。
- 空间约束：建筑占用网格，需规划道路连通性（影响效率与满意度）。

## 界面与美术
- **风格**：卡通低多边形，明亮饱和色，柔和阴影，夸张动画。
- **UI**：底部建筑栏、左上资源面板（金币/人口/ESG）、右上任务与事件提示，中部网格视图。
- **可视化**：开启 ESG 视图热力图（碳排、绿化、就业），帮助决策。

## 技术方案（示例）
- **前端**：TypeScript + React 或 Svelte；渲染使用 PixiJS/Three.js 处理 2.5D 视角。
- **状态管理**：Redux Toolkit 或 Zustand；存档使用 IndexedDB/LocalStorage。
- **模拟**：离线产出结算、建筑网格数据结构（四叉树/稀疏矩阵）、A* 路径用于交通/连通性判定。
- **音频**：WebAudio 背景乐与交互音效，音量分轨。

## 最小可玩版本（MVP）范围
1. 单张小型地图，基础住宅/商店/工厂/风机/公园/道路 6 类建筑。
2. 金币与人口循环，建筑自动产出，简单维护成本。
3. ESG 三项指标计算与热力图切换。
4. 基础任务线与一条随机事件。
5. 存档/读档、撤销/重做。
